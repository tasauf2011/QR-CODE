# QR CODE GENERATOR

A simple QR Code Generator built with Python.

## Features

- Generate QR codes from text or URLs.
- Simple graphical user interface using Tkinter.
- Display generated QR codes inside the application.
- Save generated QR codes as PNG images.

## Technologies Used

- Python
- Tkinter
- qrcode
- Pillow

## Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## How to Use

1. Open the application.
2. Enter your text or URL.
3. Click the Generate QR Code button.
4. Your QR code will appear in the window.
